# 红外夜灯遥控器需求

## 目标

使用 `Stc8hBase` 基础库开发一个新的 STC8H1K08 红外夜灯遥控器。设计以当前硬件和交互目标为准，不继承旧工程实现方式。基础库通过引用接入，本项目不复制、不修改基础库源码。

## 硬件

- MCU：STC8H1K08。
- 系统时钟：内部 IRC 6MHz。
- 红外发射：P1.0，使用 PWMA CH1 产生约 38kHz 载波。
- 指示 LED：P1.1，默认启用，首次按键确认时短闪一次。
- 按键：外部上拉，按下为低电平。

| 功能 | 引脚 | 外部中断 | 命令 | Repeat |
| --- | --- | --- | --- | --- |
| 开关 | P3.2 | INT0 | 0x11 | 否 |
| 加亮 | P3.3 | INT1 | 0x22 | 是 |
| 减亮 | P3.6 | INT2 | 0x33 | 是 |
| FN1 | P3.7 | INT3 | 0x51 | 否 |
| FN2 | P3.0 | INT4 | 0x52 | 否 |

## 交互

1. 任意按键按下后，由外部中断从掉电模式唤醒。
2. 消抖确认后，LED 短闪约 5ms，并发送一帧完整 NEC 命令。
3. 加亮、减亮键持续按住时，在完整 NEC 帧结束后约 40ms 发送第一次标准 NEC repeat 帧。
4. 后续 repeat 周期约 110ms，松手后停止。
5. 开关、FN1、FN2 只单发一次；发送后最多等待约 80ms 确认释放，以改善快速连点。若仍按住，则不重复发送并允许进入掉电模式。
6. 空闲时关闭 LED 和红外输出，并进入掉电模式。

## 成功标准

- 5 个按键命令码正确。
- `0x22`、`0x33` 长按产生标准 NEC repeat。
- 其他按键按住不连发。
- LED 只在首次确认时短闪，不跟随红外载波。
- 空闲进入掉电模式，下一次按键可唤醒。
- 本项目只引用 `Stc8hBase`，不修改基础库文件。
